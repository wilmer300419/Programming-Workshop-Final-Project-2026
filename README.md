## 📌 About the Project

This repository contains the development and documentation of the final project for the **Programming Workshop** course at **Universidad Manuela Beltrán**, within the **Software Engineering** program.

The main purpose of this repository is to store, organize, and develop the project throughout the semester. Each team member will contribute from their respective area of responsibility, working collaboratively to progressively build and improve the project.

The development process will focus on applying the programming concepts and skills acquired throughout the course, with the objective of completing a **Minimum Viable Product (MVP)** by the end of the semester.

---

## 🎯 Project Objectives

* Apply programming concepts learned throughout the course.
* Develop a functional software project collaboratively.
* Organize and document the project's source code and resources.
* Assign responsibilities and areas of work among team members.
* Continuously improve the project throughout the semester.
* Develop and deliver a functional **Minimum Viable Product (MVP)**.
* Strengthen teamwork, problem-solving, and software development skills.

---

## 🛠️ Development Approach

The project will be developed incrementally throughout the semester. Each team member will work on specific areas of the project according to their assigned responsibilities.

The development process will include:

1. **Project Planning** – Definition of the project scope, requirements, and objectives.
2. **Task Distribution** – Assignment of responsibilities among team members.
3. **Development** – Implementation of the project's features and functionality.
4. **Integration** – Combination of the different components developed by the team.
5. **Testing** – Verification and validation of the project's functionality.
6. **Documentation** – Recording the project's development process and technical information.
7. **MVP Completion** – Delivery of a functional Minimum Viable Product.
