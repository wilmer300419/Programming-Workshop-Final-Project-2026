## Descripción

Programa desarrollado en Python que permite crear una cuadrícula interactiva y seleccionar posiciones mediante coordenadas X y Y.

El programa permite:

* Crear una cuadrícula de mínimo 8x8.
* Seleccionar coordenadas.
* Visualizar las coordenadas seleccionadas.
* Reiniciar la cuadrícula.
* Cambiar el tamaño de la cuadrícula.

## Ejecución

Para ejecutar el programa se necesita tener instalado **Python 3**.

Ejecutar el archivo desde la terminal:

```bash
python nombre_del_archivo.py
```
